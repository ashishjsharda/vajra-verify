# Security policy

Do not open a public issue for a suspected secret leak, code-execution issue, or vulnerability.

Report it privately through GitHub: on this repository, open the **Security** tab and choose **Report a vulnerability**. Include:

- A short description
- Reproduction steps
- Potential impact
- Any relevant version or commit SHA

Please do not include live credentials in the report. If a receipt ever prints an unredacted secret value, that is a security bug; report it here, not in a public issue.

Vajra Verify makes no network calls and sends no code anywhere. Any behavior that contradicts this is also a security issue.
