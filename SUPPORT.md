# Support

- **Bug or wrong finding:** open a [bug report](../../issues/new?template=bug_report.yml). A minimal diff that reproduces it helps most.
- **Idea for a new rule:** open a [rule request](../../issues/new?template=rule-request.yml).
- **Questions and usage help:** use [GitHub Discussions](../../discussions).
- **Security issues:** see [SECURITY.md](SECURITY.md). Do not file them publicly.

Vajra Verify is maintained by Ashish Sharda on a best-effort basis.
